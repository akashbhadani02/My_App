Tablet purchase update
====================
- Student Photo is required during tablet purchase.
- Student Marksheet (JPG/PNG/WEBP image) is now required during tablet purchase.
- Both UPI and Wallet purchase requests validate and save both documents.
- Admin Tablet Orders page has separate View Photo and View Marksheet buttons.
- Student status endpoint hides both uploaded documents.
- JSON request body limit increased to 6 MB to accommodate both compressed uploads and payment proof.

For deployment, replace the corresponding project files with this updated project and install dependencies using npm install. Do not deploy .env from this archive; keep your existing server secrets configured separately.
