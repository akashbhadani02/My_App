# Aducate UI Upgrade

## Included
- Modern responsive student dashboard
- Learning progress, XP, streak and question stats
- Quick Practice shortcuts
- Beginner / Intermediate / Advanced learning paths
- 30-day challenge visual with today progress
- Mobile-first app-style layout
- Refreshed login page styling
- Updated PWA manifest branding

## Compatibility
Existing authentication, wallet, quiz, activity, add-ons, profile, notifications, subscription, book and admin endpoints are kept intact.

## Run
1. `npm install`
2. Configure the existing environment variables (including MongoDB/JWT settings).
3. `npm start`
