ADUCATE ENGLISH - PROFESSIONAL BLUE THEME

This package starts from the existing full project; application structure, backend routes,
models, authentication, wallet, quizzes, activities, profile, admin tools, AI coach, and
image assets are retained. The visual layer has been unified around a professional navy
and blue palette inspired by the approved dashboard reference, with white cards, pale blue
surfaces, soft borders/shadows, and restrained green/purple/orange status accents.

Branding:
- Visible product wordmark: Aducate English
- Updated logo seal: ADUCATE / ENGLISH
- PWA name and theme color updated to Aducate English / navy blue

Deployment:
- .env and .git were excluded from the archive; keep existing Vercel environment variables.
- node_modules is excluded; run npm install or npm ci before local execution.
- Please test login/register, quiz flow, wallet/withdrawal, activities, profile, notifications,
  book flow, AI Coach, and admin tools before production use. Full live browser QA against the
  production database has not been performed.
